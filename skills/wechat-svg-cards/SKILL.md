# 公众号 SVG 动画卡（单独做卡）

给林月半子（LQ）的公众号文章做「会动的配图」。**整篇排版时不用这个 skill**，直接在文章里写 `svg-xxx` 代码块，由 `wechat-article-layout` 一起排。这个 skill 只用在：文章已经排好了，想单独补一两张卡；或者只要卡片、不要排版。

两个 skill 用的是同一份脚本 `scripts/layout.py`，画出来的卡片完全一样。

## 什么时候用动画卡

- 一个**概念要一眼看懂** → `svg-concept`
- 一套**可照着做的步骤** → `svg-steps`
- 一条**指令或句子要拆开讲** → `svg-breakdown`
- **以前 vs 现在** → `svg-compare`
- 一张想让读者看懂的**表格** → `svg-table`；有真实数字的对比 → `svg-bars`
- 按时间推进的几个节点 → `svg-timeline`
- **随时间变化的流程**，截图只能截一帧 → `svg-phone`

不要用在：真实截图能证明的地方（截图比 SVG 可信，商单尤其如此）；靠语气取胜的段落（结尾、短板）。

**数量**：一篇最多 3 张，同一节最多 1 张。

## 步骤

**省时规则**：脚本已经写好、测过，不要读源码，不要自己另写 Python 拼 SVG，默认不截图。

1. 从文章里挑出要做成卡的内容，文字全部取自原文，不编数字、不编功能。
2. 写一个 `cards.md`，开头固定三行，下面每张卡一个代码块（写法见下表，完整示例在 `examples/cards.md`）：
   ```
   ---
   outro: false
   ---
   ```
3. 运行：`python3 <skill 目录>/scripts/layout.py cards.md --out out`
   - 要指定风格或配色时加 `--style neo --theme blue`。风格有 `std` `mag` `min` `geek` `bold` `neo`，配色有 `orange` `blue` `teal` `ink` `navy` `violet` `rose` `amber` `morandi`。要和正文用同一套。
   - 命令会打印自查结果。写错格式的卡会提示是哪一张，按提示改了再跑。
4. 交付 `out/…-公众号排版.html`：用 Chrome 打开，顶部可以换风格和配色，点「复制全文到公众号」，到公众号编辑器的空行粘贴。几张卡是一起复制的，粘贴后把它们分别拖到对应位置；想一张一张复制，就每张卡单独写一个 md。

## 卡片写法

| 写法 | 画面 |
|---|---|
| ` ```svg-concept 标题 `：第一行一句大白话；`旧东西 \| 节点 \| 节点`；`新东西 \| 节点 \| 节点 \| 节点`；可选一行 `! 关键差别…` | 灰色虚线是旧的，主题色实线一段段画出来、节点点亮，虚线框圈出关键差别 |
| ` ```svg-steps 标题 `，每行 `步骤 \| 补充说明` | 步骤卡依次滑入，右侧对勾画出（3–5 步） |
| ` ```svg-breakdown 标题 `，每行 `标签 \| 内容` | 标签胶囊弹出，荧光笔逐行扫过；★ 那行是实心色块 |
| ` ```svg-compare 标题 `，第一行 `左标题 \| 右标题`，之后每行 `以前 \| 现在` | 左边灰色 ×，右边主题色 ✓ |
| ` ```svg-table 标题 ` + 标准 Markdown 表格 | 每行从左滑入，★ 行加主题色边框 |
| ` ```svg-bars 标题 `，每行 `名称 \| 数值 \| 显示文字` | 横向柱子依次长出，最大值用主题色 |
| ` ```svg-timeline 标题 `，每行 `时间 \| 事件` | 横线画过去，节点依次点亮（最多 6 个） |
| ` ```svg-phone 标题 `：第一行写「按 XX 演示」；之后每行 `功能名 \| 谁说的或时间 \| 气泡里的话` | 左边手机一幕幕轮播，右边功能列表高亮跟着走（3–5 幕） |

- 任何一行加 `★` 表示重点；最后加一行 `> 一句话` 是卡片底部金句（`svg-phone` 除外）。
- 标签和步骤标题控制在 12 字以内。
- `svg-phone` 是示意，不是真实截图，第一行一定写清「按 XX 演示」。
- 商单卡片只写通用词（「降压药」），不出现竞品名。同一个英文词不要在一张卡里出现两次。

## 小红书导出

小红书不支持 SVG。用户要小红书图时才做：用 Playwright 打开复制页，把动画定到最后一帧再截图（`deviceScaleFactor: 2`）：

```js
await page.evaluate(t => document.querySelectorAll('svg').forEach(s => { s.pauseAnimations(); s.setCurrentTime(t) }), 9)
```

## 公众号硬限制（脚本已处理，改脚本时别破坏）

- 不能用 `id`、`class`、`<style>`、`<script>`、渐变、滤镜、`<use>`、clipPath、外部字体。
- 动画只能用 SMIL：`<animate>`、`<animateTransform>`、`<set>`。
- 不要 emoji。图片只能用 `mmbiz.qpic.cn` 的地址。
- 标题从第一帧就可见，卡片循环播放。
